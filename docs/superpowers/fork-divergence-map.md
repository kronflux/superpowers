## Nature legend

The four base natures from the plan (`router-pointer` / `hook-point` / `net-new` / `overlay`)
plus two extensions this map needed: `moved` (pure renames that filename-matching alone would
misclassify) and `identity` (same-named upstream files with fully diverged fork content):

| Nature | Meaning |
|---|---|
| `net-new` | File or directory has no upstream counterpart at all — fork-authored from scratch. |
| `router-pointer` | File exists upstream too; the fork-owned part is a pointer to a `skills/shared/conductor/*.md` adapter or the routing table. Everything else in the file is upstream-shared prose — apply upstream hunks there directly. |
| `hook-point` | Fork-owned mechanism file: a hook script, a generated manifest, a gate, or a test guarding one. Not skill prose. |
| `overlay` | Generated harness-surface mirror, regenerated wholesale by a sync script. Never hand-diffed; dedupe to one row pointing at the generator. |
| `moved` | Relocated within the fork's own tree. Upstream, if it has an equivalent, still uses the old name/location — do not path-match by filename alone. |
| `identity` (extension) | File exists upstream under the same name/purpose, but fork content is deliberately 100% diverged (branding, contributor policy, byte budgets). Never apply hunks wholesale; port only factual details worth carrying over, as manual prose edits. |
